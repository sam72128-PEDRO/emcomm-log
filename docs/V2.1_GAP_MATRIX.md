## Plan (spec §12)

1. Schema v4: stations (logbook station/assignment), operator sessions (shift history), immutable
   location value rows with two per-entry links, HAM activation fields; app-DB profile additions;
   archived-logbook migration on a copy. Pre-migration backup already exists.
2. Identity UI: Logbook → Station / Assignment; Active Operator + Switch Operator (time, note, draft
   handling); shift boundaries and operator filter in the Traffic Log; HAM station callsign from the
   station, not the person.
3. Quick Entry: local recents (callsign, station, frequency), session defaults with defined retention for
   Save & Add Another, location subsection (two locations), non-blocking warnings.
4. Desktop GPS: `LocationProvider` with NMEA-serial (USB / Bluetooth SPP serial), gpsd (loopback),
   OS location where an API is reachable; recorded NMEA/gpsd fixtures; Settings → Location & GPS.
5. ADIF 3.1.8 with QRZ / POTA activator / SOTA activator / SOTA chaser presets, preview and validation,
   precise-coordinate export policy.
6. Regression (V1/V2 suites, E2E), docs (GPS setup, operator vs station, HAM export, privacy), release.
