# EMCOMM LOG 2.2 — difference matrix against the V2.2 handoff package

Package: `EMCOMM_LOG_V2.2_Claude_Code_Package` (EMLOG-2.2-SHARED-2026-11-04, desktop and Android specs).
Baseline: `main` = 2.1.0 (`9526918`, tagged `v2.1.0`), audited from source on 2026-11-04, not from the
release documents. Logbook schema is **v4**; 2.2 adds **v5**.

Key: **present** = already in 2.1 and tested · **extend** = exists, needs additions · **missing** · **platform
risk** = depends on native APIs or hardware not yet exercised.

## Feature A — attachments (`ATT-*`)

| Item | Status | Where / notes |
|---|---|---|
| Attach file (native picker), managed copies | **present** | `attachments` table; content-addressed files under `attachments/<sha256>.<ext>`; hash verified on finalize (`entries.rs::finalize_attachment`). |
| Draft staging survives crash | **present** | `.staging/` + drafts reference `staging_id`; `drafts.rs::referenced_staging` keeps them. Needs tests for the new sources. |
| `.emlog` / backups carry originals + hashes | **present** | Package and backup copy the whole folder; hash checks on import. |
| Caption, source (`file`/`drag_drop`/`paste`/`camera`/`photo_picker`) | **missing** | Schema v5 columns on `attachments`. |
| Remove attachment as a recorded entry change | **missing** | No removal path today; add to Save Changes (revision `edit`), keep bytes while referenced. |
| Drag-and-drop, clipboard image paste (desktop) | **missing** | Tauri window drag-drop event; paste only inside the attachment target. |
| Thumbnails / safe preview, Open / Save As | **extend** | Open exists (`open_attachment`); add bounded thumbnails (decode cap), Save As. |
| Magic-byte check, executable refusal, size warning, free-space check, progress/cancel | **extend** | Size limit exists; add sniffing, warning at 25 MiB, streaming copy with progress/cancel. |
| EXIF / location privacy in shared reports | **missing** | Reports never embed originals by default; optional attachment list/appendix strips metadata. |
| Android camera / Photo Picker / SAF | **platform risk** | Android-native adapters; done on the Android branch (see below). |

## Feature B — related communications (`REL-*`)

| Item | Status | Notes |
|---|---|---|
| Links between entries, 5 types, canonical symmetric pairs, no self/duplicate | **missing** | New `entry_links` table (v5), FK to `entries`, unique index on canonical (source, target, type). |
| Audit of link create/remove | **missing** | `entry_revisions.action` has a CHECK of create/edit/void/restore; changing it means rebuilding the history table. 2.2 records link changes in a separate append-only `entry_link_events` table instead — history table untouched. |
| One-hop panel, search within logbook, voided shown | **missing** | Entry Details panel + "Link existing entry" dialog reusing `list_entries` search. |
| `.emlog` / backup carry links | **present by design** | Whole database travels; import validates both endpoints exist. |

## Feature C — Important / Follow-up (`FLAG-*`)

| Item | Status | Notes |
|---|---|---|
| Flag for Report, Favorite | **present** | `entries.flagged`, `entry_favorites`. Untouched. |
| Important, follow-up state/due/note/resolved | **missing** | v5 columns on `entries`; changed via Save Changes so every change is a revision (history kept). |
| Traffic Log filters, dashboard Open Follow-ups → filtered log | **missing** | Extends `EntryQuery` and existing filter bar. |
| Independent of message handling status | **present by design** | Separate columns; no coupling. |

## Feature D — station directory (`DIR-*`)

| Item | Status | Notes |
|---|---|---|
| Local suggestions from history | **present** (2.1 recents) | `recents.rs` + datalists. |
| Per-logbook directory with types, aliases, tags, notes | **missing** | v5 `station_directory` table; Settings → Logbook Directory; Save to Directory from an entry. |
| Directory ranked above history, snapshot copy into entry | **missing** | Entries keep plain text (as 2.0 channel plan), so later directory edits never rewrite history. |

## Feature E — ADIF import (`ADIF-*`)

| Item | Status | Notes |
|---|---|---|
| ADIF 3.1.8 export + presets | **present** | 2.1; must stay unchanged (regression tests exist). |
| ADI parser (lengths, EOH/EOR, case, Unicode), bounded | **missing** | New `export/adif_import.rs` (pure Rust, shared with Android). |
| Preview, duplicates incl. POTA/SOTA context, atomic import, batches, extras | **missing** | v5 `adif_import_batches`, `entry_import_source`; one transaction per import. |

## Feature F — export review (`EXP-*`)

| Item | Status | Notes |
|---|---|---|
| Scopes: all / range / filter / selected | **present** | Reports scopes; Traffic Log selection carried as `ids`. |
| ICS 213 (messages only), 214 (period), 309 (selected) with exclusion reasons | **extend** | Preview functions exist for 213/214; unify into one Review step. |
| Per-row check/uncheck by immutable ID, counts | **missing** | Review stage in Reports and the ICS dialogs. |
| Snapshot IDs + revision numbers, block if changed before write | **missing** | Export request carries `{id, revision}` list; core rejects on mismatch. |
| Temp-file + rename, no partial output | **present** | 2.0 export contract. |
| Attachment reference list / image appendix (opt-in) | **missing** | PDF/DOCX optional. |

## Data, safety, packaging

| Item | Status | Notes |
|---|---|---|
| Versioned migrations, verified pre-migration copy, archived logbooks viewed from a copy | **present** | 2.1 (`migrate.rs`, `logbook.rs`). v5 follows the same path. |

| macOS local build + smoke | **present** | Per DECISIONS #25. |

## Android

The tablet app lives on branch `android-2.1` (another session; shell and UI only, it shares `core/`). Plan:
build the shared core, schema v5 and desktop UI here on `v2.2`; then the Android branch is rebased onto `v2.2`
and adds only the native adapters (camera capture, Photo Picker, SAF document picker and
`ACTION_CREATE_DOCUMENT`, touch layouts). One schema, one parser, one duplicate rule.

## Not in 2.2 (spec §1)

Net Control, CAT/radio control, handoff report, cloud/sync, accounts, internet lookup, task management, new
dashboard, ADX/XML ADIF, video/voice.
